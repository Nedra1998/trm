## About The Project

![Menger Sponge Example](docs/examples/menger.png)

_TRM_ is a tiny ray marcher written in C++. It is intended to be used as a
simple and lightweight ray marcher for educational purposes. It is not intended
to be used in production. It is designed to be simple to understand, but that
results in having many limitations, and it is not optimized for performance.
But it is a good starting point for learning about ray marching and ray
tracing.

A large aspect of the project is to collect imperical measurements to quantify
improvements that are achived by implementing different features. To that end,
the examples provided with the library are sampled and in the documentation
includes through statistics and metrics tracking the changes to the rendering of
those scenes over time.
